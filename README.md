# Карточки Maff — генератор

Страница, которая из фото декора делает карточку 1080×1080 по шаблону Maff (плашка завода, «Сделано в России»,
нижняя панель с названием и значками) и сразу называет файл как номенклатуру в 1С, чтобы бот его подхватил.

Открывается через GitHub Pages: `https://abdumomin1.github.io/product-card-generator/`
(Settings → Pages → Branch `main`, папка `/ (root)`).

## Как пользоваться

1. Скачать фото декора с сайта завода. В имени файла должен быть артикул: `EPL240.jpg`, `50767 Дуб Лембрук.webp`,
   `K476 Ultrafloor.png`. Без артикула генератор ищет по названию декора («Дуб Лембрук.jpg»).
2. Перетащить фото на страницу (можно сразу много).
3. Проверить карточки. Если артикул есть у двух заводов (например, 5940 — Егорьевск и Сморгонь), ничего не отмечено —
   поставить галочку у нужного. Подсказать завод можно словом в имени файла: `5940 Сморгонь.jpg`.
4. «Скачать отмеченные (ZIP)» → распаковать → положить в нужную папку «Каталог» на Google Диске
   → в таблице «Каталог → Обновить сейчас».

## Откуда данные

- **Товар** — таблица «Каталог» (`1JSCgXBTlrYnvWLD-bHXfp9DCtXOKgFXZEh1zn2bBoe4`, открыта по ссылке на чтение),
  листы «Ламинат», «Паркет», «SPC»: завод, коллекция, артикул, номенклатура, модель, толщина, класс, фаска.
  Читается напрямую из Google (`gviz/tq?tqx=out:csv`). Если не загрузилась — берётся каталог бота (Apps Script),
  тогда файл называется «коллекция + декор» (бот тоже его узнаёт). Ещё запасной путь — загрузить CSV вручную.
- **Завод по артикулу:** Эггер — `EPL/EHL/EL/EC/EBL` + цифры, AGT — `PRK` + цифры; остальные — по совпадению артикула
  в таблице и по слову в имени файла (`swiss`, `ultrafloor`, `сморгонь`…). Кириллица «К405» и латиница «K405» — одно и то же.
- **Замок, влагостойкость, 4-й значок, «Сделано в России»** — настройки заводов в `brands.js`. Пустое поле = значка нет
  (ничего не выдумываем). Заполнено по готовым карточкам владельца: Эггер, Ultrablack; по сайту завода:
  Ultrafloor — Aqua Stop. Остальным нужно заполнить на странице («Настройки заводов») и прислать JSON.
- AC по классу: 31→AC3, 32→AC4, 33→AC5, 34→AC6.

## Файлы

```
index.html        страница
match.js          разбор таблицы и распознавание товара по имени файла (проверяется в Node)
brands.js         настройки заводов
card/cardgen.js   отрисовка карточки (общая с сайтом shop.maff.uz, public/card/cardgen.js)
card/*            шрифт Lato, логотип Эггер, значки и плашка «Сделано в России» из шаблона владельца
vendor/jszip.min.js  сборка ZIP (JSZip 3.10.1), лежит здесь, чтобы не зависеть от CDN
```
