Как залить этот генератор на твой GitHub Pages за 1 минуту

Чтобы открывать его по постоянной ссылке с любого компьютера или телефона

  1. Зайди на github.com/new и создай новый публичный репозиторий (например, card-generator).
  2. Сохрани код этого приложения в файл index.html. Рядом с ним в эту же папку положи свои файлы:
    • Шаблон 1.png (и/или переименуй в template_no_bevel.png)
    • Шаблон 2.png (и/или переименуй в template_bevel.png)
    • Свои файлы шрифта Lato-BlackItalic.ttf и Lato-Bold.ttf

    Скрипт при открытии страницы сам проверит наличие этих файлов в папке репозитория и автоматически подгрузит их!

  3. В репозитории нажми Add file → Upload files, перетащи туда эти файлы и нажми зеленую кнопку Commit changes.
  4. Перейди во вкладку Settings → Pages (слева в меню), в разделе Branch выбери main и нажми Save. Через 30 секунд у тебя появится твоя личная рабочая ссылка вида https://твой-логин.github.io/card-generator/.
